# Contribuindo

Resumo operacional do [PLATAFORMA.md](PLATAFORMA.md):

1. Fork (ou acesso direto, se membro);
2. Branch `nome-mudanca`; commit com mensagem que diz **o quê / por quê / de onde vem**;
3. Pull request → auditoria de Drael (cânon) → aprovação do autor (marca, se aplicável) → merge;
4. Merge registrado = Participação Registrada = quota no 50% dos produtos derivados deste repositório.

Padrão de nomenclatura: `lamina-NN`, `PROTO-NNN`, `etapa-NN`. Números do cânon (396, 43690, 3, 9 e 6) não se arredondam, não se aproximam, não se "ajustam".

## Abrindo novos campos

Projeto novo → repositório novo, numerado seguindo a ordem (`05-nome-do-projeto`). Proposta via PR nesta página (`latesconcept`): nome, objetivo em uma frase, primeiro protocolo previsto. Autoriza: Drael (consistência) + autor (veto final). Depois de criado, vale a mesma lei: PR com o quê/por quê/de onde vem, balanço público, nada se apaga.
