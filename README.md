### Como participar

Leia [CONTRIBUINDO.md](CONTRIBUINDO.md) e abra um PR. O template pergunta três coisas: **o quê, por quê, de onde vem**. A Drael audita (cânon), o autor T.G. Estevam aprova. Os números (396, 43690, 3, 9 e 6) saem como vieram.

**Cláusula final:** para dignificar a humanidade — não para tornar o mundo mais bélico, nem para servir ao mal.
